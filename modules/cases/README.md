# Cases Package Ownership

This package is the single canonical home for common case management.

Planned responsibilities:

- Case creation and validation
- Case opening, listing, archiving and status changes
- FIR/reference, investigator and police-unit metadata
- Target and suspect registration
- Source-file/evidence registration
- CCTV sighting and time-window configuration
- Audit logging
- Case-specific report paths

Do not create separate case managers inside CDR, Tower Dump or IPDR modules.
